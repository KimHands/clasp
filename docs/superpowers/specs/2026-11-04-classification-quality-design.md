# 분류 품질 설계

개편 범위 B의 세 번째 묶음이다. 평가 수치는 `docs/evaluation.md`에 있다.

## 문제

- 파일명 패턴이 형식이 분명한 확장자를 덮어쓴다(`report_template.py`가 문서).
- `paper`가 `wallpaper`에도 걸린다.
- 범용 형식의 고정 신뢰도 0.70을 임베딩 점수(측정 최고 0.574)가 넘지 못해 Tier 2가 카테고리를 바꾸지 못한다.
- 두 단계가 일치하면 평균 때문에 신뢰도가 내려간다(0.82 → 0.706).
- 수동 분류와 규칙이 재스캔 화면에 반영되지 않고, 화면과 실제 이동이 어긋난다.
- 변경 없는 파일도 매번 본문을 다시 읽는다.

## 결정

| 근거 | 신뢰도 | 비고 |
|---|---|---|
| 수동 분류 | 1.0 | |
| 일치 보너스 | `max(T1, T2) + 0.05`, 상한 0.95 | 일치하면 내려가지 않는다 |
| 사용자 규칙 | 0.85 | |
| 형식이 분명한 확장자 | 0.85 | Tier 3를 호출하지 않는다 |
| 파일명 패턴(범용 형식만) | 0.82 | 영어 키워드는 단어 경계 적용 |
| 범용 형식(pdf, docx, doc, txt, md, hwp, rtf) | 0.50 | 내용 분석이 뒤집을 수 있다 |

- Tier 2의 "코드" 키워드와 Tier 3 프롬프트에서 주제어(보안, 네트워크 등)를 뺀다. 기술을 다룬 보고서는 문서다.
- 분류 설정(규칙, 확장자, 카테고리, 민감 키워드, 로컬 LLM, `CLASSIFIER_VERSION`)의 지문을 폴더별로 저장한다. Codex 리뷰가 전역 지문의 누락을 재현해 폴더별로 바꿨다. 달라지면 변경 없는 파일도 다시 분류한다.
- 변경 없고 이전 결과가 있는 파일은 표지와 본문을 다시 읽지 않는다.
- 결과 목록은 그 스캔의 파일에 달린 수동 분류를 스캔과 무관하게 우선한다.

## 범위 밖

- 임계값을 기계적으로 학습하는 보정: 표본이 작아 과적합이 더 큰 위험이다.
- 임베딩 모델 교체.
